# 对外 API 清单

> 本文档聚焦开源版对外可用的 API 面，帮助外部开发者了解"可以稳定依赖什么"。
> 内部实现（如 DefaultPluginManager 的具体实现类）不属于对外 API，变更不受兼容性约束。

## 1. 模块依赖关系（边界）

```
                    ┌─────────────────────────────────────┐
                    │  spring-boot3-brick-bootkit-web     │
                    │        (Web 管理控制台)              │
                    └──────────────┬──────────────────────┘
                                   │ depends on
                    ┌──────────────▼──────────────────────┐
                    │  spring-boot3-brick-bootkit          │
                    │           (主集成模块)               │
                    └──────────────┬──────────────────────┘
                                   │ depends on
         ┌─────────────────────────┼─────────────────────────┐
         │                         │                         │
┌────────▼────────┐     ┌─────────▼──────────┐   ┌────────▼─────────┐
│   bootstrap     │     │       core          │   │     loader       │
│  (插件侧引导)    │     │   (核心能力)        │   │   (加载器)       │
└────────┬────────┘     └─────────┬──────────┘   └────────┬─────────┘
         └────────────────────────┼────────────────────────┘
                                  │ depends on
                         ┌────────▼──────────┐
                         │     common         │
                         │   (通用基础)       │
                         └───────────────────┘
```

**模块边界规则**：

| 模块 | 对外职责 | 依赖方向 |
|---|---|---|
| `common` | 常量、工具类、公共数据结构（如 DependencyPlugin） | 无框架内依赖 |
| `loader` | 插件类加载、启动链路 | → common |
| `core` | 插件生命周期、事件总线、安全、配置、性能、隔离等核心能力 | → common |
| `bootstrap` | 插件侧 `SpringPluginBootstrap` 引导基类与注解 | → core |
| `spring-boot3-brick-bootkit` | 主集成：PluginManager/Operator、SPI、自动装配 | → core/loader/bootstrap/common |
| `web` | Web 控制台与 REST API | → spring-boot3-brick-bootkit |
| `sdk` | 插件侧注解（@BrickService 等）与事件装配工具 | → core |
| `scripts` | 脚本执行与调度 | → spring-boot3-brick-bootkit |
| `maven-packager` | 插件 Maven 打包插件 | → common |

## 2. 主框架对外 API（spring-boot3-brick-bootkit）

### 2.1 核心接口

| 接口 | 说明 |
|---|---|
| `com.zqzqq.bootkits.core.PluginManager` | 插件管理器：load/install/start/stop/uninstall/reload/verify/parse/close |
| `com.zqzqq.bootkits.core.PluginInfo` | 插件信息视图（pluginId/pluginPath/state/descriptor） |
| `com.zqzqq.bootkits.core.PluginInsideInfo` | 插件内部信息（含 ClassLoader、EnhancedPluginState） |
| `com.zqzqq.bootkits.core.descriptor.PluginDescriptor` | 插件描述符（pluginId/version/dependencyPlugin/requires 等） |
| `com.zqzqq.bootkits.integration.operator.PluginOperator` | 插件操作门面（upload/install/upgrade/verify/parse） |
| `com.zqzqq.bootkits.integration.user.PluginUser` | 插件使用者门面 |

### 2.2 SPI 扩展点（宿主/插件可注入）

| SPI | 用途 | 说明 |
|---|---|---|
| `core.admission.PluginAdmissionCheck` | 安装/启动准入检查 | 容器 Bean 自动收集，默认含 `PluginDescriptorAdmissionCheck` |
| `integration.spi.PluginLifecycleExtension` | 插件生命周期钩子 | 支持 Spring Bean + Java SPI 两种来源，覆盖 install/start/stop/uninstall |
| `integration.rollout.PluginRolloutProbe` | 灰度发布探针 | `rolloutMode=gray` 时升级逐探针校验，失败自动回滚 |
| `core.lock.ClusterLockProvider` | 集群分布式锁 | 默认 NoOp/文件锁；引入 Redis 后自动用 `RedisClusterLockProvider` |
| `core.communication.PluginServiceRegistry` | 跨插件服务注册/发现 | Bean 注入即用；插件启动自动扫描 `@PluginService`/`@BrickService` |
| `core.security.PluginSecurityManager` | 插件安全扫描/权限/策略 | 接入安装准入管线 |
| `core.config.PluginConfigurationManager` | 插件配置热更新/版本/回滚 | 由 core `PluginConfigurationAutoConfiguration` 注册 |
| `core.performance.PluginPerformanceAnalyzer` | 插件性能分析 | 与 `QuotaManager`/`PluginResourceMonitor` 配合 |
| `core.eventbus.PluginEventBus` | 插件事件总线 | 支持同步/异步发布，SDK `EventBusAutoConfigure` 自动装配监听器 |
| `core.dependency.PluginDependencyManager` | 依赖图/兼容性/影响面分析 | Bean 注入即用 |
| `integration.cluster.ClusterNodeRegistry` | 集群节点注册/心跳 | `clusterEnabled=true` 时生效 |

### 2.3 注解

| 注解 | 位置 | 说明 |
|---|---|---|
| `annotation.Extract` | 主框架 | 标记主程序侧扩展，启动时注册进 ExtractFactory |
| `annotation.Caller` / `annotation.Supplier` | 主框架 | 主程序与插件调用标记 |
| `core.communication.annotation.PluginService` | core | 插件服务注册（interfaceClass/version/priority/singleton/enabled） |
| `sdk.annotation.BrickService` | sdk | SDK 版服务注册注解（兼容自动扫描） |
| `sdk.annotation.BrickServiceReference` | sdk | 跨插件服务自动注入（字段级，可 optional） |
| `sdk.annotation.BrickEventListener` | sdk | 事件监听方法注解（EventType 数组/priority/async） |
| `sdk.annotation.BrickPlugin` | sdk | 插件元信息注解（id/name/version/dependsOn） |

## 3. Web REST API（spring-boot3-brick-bootkit-web）

统一前缀：`${plugin.web.api-prefix:/plugins-web/api}`。鉴权由 `plugin.web.auth.mode` 控制（disabled/delegate/strict）。

### 3.1 插件管理

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/plugins` | 插件列表（分页/状态/关键字） |
| GET | `/plugins/all` | 全部插件 |
| GET | `/plugins/{pluginId}` | 插件详情 |
| POST | `/plugins/upload` / `/plugins/upload/temp` | 上传插件 |
| POST | `/plugins/install` / `/plugins/install/temp` | 安装插件 |
| POST | `/plugins/{pluginId}/start\|stop\|restart` | 生命周期操作 |
| DELETE | `/plugins/{pluginId}` | 卸载 |
| POST | `/plugins/verify` | 验证插件 |
| GET | `/plugins/{pluginId}/download` | 下载插件 |
| GET/DELETE | `/plugins/upload-history` | 上传历史 |

### 3.2 环境自检与监控

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/doctor` | 环境自检报告 |
| GET | `/doctor/export/text\|json` | 自检报告导出 |
| GET | `/monitor/overview\|memory\|cpu\|threads\|system` | 监控数据 |
| GET | `/monitor/threads/detail\|thread-pools\|history` | 线程/历史监控 |

### 3.3 增强能力（2026-08 起新增）

| 分组 | 方法 | 路径 |
|---|---|---|
| 安全中心 | GET/POST | `/security/scan/{pluginId}`、`/security/scan?path=`、`/security/policy`、`/security/permissions/*` |
| 服务注册中心 | GET | `/registry/statistics`、`/registry/services`、`/registry/plugins` |
| 配置热更新 | GET/PUT/POST/DELETE | `/configurations`、`/configurations/{pluginId}`、`/configurations/{pluginId}/versions`、`/configurations/{pluginId}/rollback` |
| 性能分析 | GET/POST | `/performance/analyze/{pluginId}`、`/performance/usage`、`/performance/quota/{pluginId}`、`/performance/scores` |
| 集群管理 | GET/POST | `/cluster/overview`、`/cluster/nodes`、`/cluster/plugins/states`、`/cluster/plugins/sync` |
| 依赖分析 | GET | `/dependency/graph`、`/dependency/{pluginId}`、`/dependency/{pluginId}/compatibility`、`/dependency/{pluginId}/impact`、`/dependency/matrix` |
| 灰度发布 | GET/POST | `/rollout/config`、`/rollout/probes`、`/rollout/check/{pluginId}` |
| 事件总线 | GET | `/eventbus/stats`、`/eventbus/types`、`/eventbus/recent` |
| 日志查看 | GET | `/logs`、`/logs/file` |

完整路由对照源码：`spring-boot3-brick-bootkit-web/src/main/java/com/zqzqq/bootkits/web/controller/api/` 下各 Controller。

## 4. 配置项（`plugin.*`）

详见 `docs-website/src/content/generated-config-keys.json`（由 `npm run generate-config-index` 从源码生成）。常用项：

| 配置 | 默认 | 说明 |
|---|---|---|
| `plugin.enable` | true | 总开关 |
| `plugin.runMode` | dev | dev/prod |
| `plugin.mainPackage` | 自动探测 | 主应用包名 |
| `plugin.pluginPath` | - | 插件目录列表 |
| `plugin.admissionMode` | warn | off/warn/enforce |
| `plugin.clusterEnabled` / `clusterSharedPath` | false | 集群模式与共享目录 |
| `plugin.rolloutMode` | direct | direct/gray |
| `plugin.lifecycleExtensionsEnabled` | true | 生命周期扩展开关 |
| `plugin.web.auth.mode` | delegate | disabled/delegate/strict |
| `plugin.configuration.enabled` | true | 配置热更新开关 |
