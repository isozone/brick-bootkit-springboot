# 兼容与支持矩阵

## 📋 概述

本页明确列出开源版当前承诺支持、并由 CI 覆盖到的运行组合。以“说清楚”为第一原则：不在矩阵里的组合不是不能用，而是不在承诺和回归范围之内。

## 🧪 官方基线

| 项目 | 当前基线 | 说明 |
| --- | --- | --- |
| Java | JDK 17 | 父工程 `java.version=17` |
| Spring Boot | 3.5.5 | 父工程 `spring-boot.version=3.5.5` |
| Maven | 3.6+ | 建议最低版本 |
| Docs Node | 20 | docs-website CI 使用 Node 20 |

> 基线版本均由父工程 `pom.xml` 与 `.github/workflows/ci.yml` 双源约束，修改前需同步两处。

## 🤖 CI 当前覆盖

- GitHub Actions 当前基线为 `ubuntu-latest + Java 17`
- 稳定测试模块当前覆盖 `loader / core / spring-boot3-brick-bootkit`
- docs-website 使用 `Node 20` 执行校验和构建

## ⚠️ 不在承诺范围

以下组合不在回归矩阵，遇到问题优先按“升级到基线”处理，不视为框架缺陷：

- Java 8 / 11 / 21 及以上：未做构建与字节码验证
- Spring Boot 2.x：brick-bootkit 3.x 仅面向 Spring Boot 3.x
- 非 Linux runner（Windows / macOS）下的 Maven 构建：CI 不覆盖，本地可用但回归不保证
- Gradle 构建：当前仅 Maven 打包器经过验证

## 🔄 版本同步约定

任何基线变更（Java / Spring Boot / Maven / Node）必须同步：

1. 父工程 `pom.xml` 的 `<properties>` 版本号
2. `.github/workflows/ci.yml` 的 setup-java / setup-node 版本
3. 本页“官方基线”表格
4. README 顶部“快速接入”章节的环境要求
