# 兼容与支持矩阵

## 📋 概述

本页明确列出开源版当前承诺支持、并由 CI 覆盖到的运行组合。以“说清楚”为第一原则：不在矩阵里的组合不是不能用，而是不在承诺和回归范围之内。

## 🧪 官方基线

| 项目 | 当前基线 | 说明 |
| --- | --- | --- |
| 框架版本 | 4.0.10 | 父工程 `<version>` |
| Java | JDK 17 | 父工程 `java.version=17` |
| Spring Boot | 3.5.5 | 父工程 `spring-boot.version=3.5.5` |
| Maven | 3.6+ | 建议最低版本（mvnw 内置 3.9.11） |
| Docs Node | 20 | docs-website CI 使用 Node 20 |
| 前端构建 Node | 20 | vue3 控制台 CI 使用 Node 20 |

> 基线版本均由父工程 `pom.xml` 与 `.github/workflows/ci.yml` 双源约束，修改前需同步两处。

## 🧩 模块 JDK / 构建矩阵

所有模块统一继承父工程，编译基线均为 **JDK 17 + Spring Boot 3.5.5**：

| 模块 | 角色 | 打包 | 对外依赖 |
| --- | --- | --- | --- |
| `common` | 通用基础 | jar | 无框架内依赖 |
| `core` | 核心能力 | jar | common |
| `loader` | 类加载/启动 | jar | common |
| `bootstrap` | 插件侧引导 | jar | core |
| `spring-boot3-brick-bootkit` | 主集成 | jar | core/loader/bootstrap/common |
| `web` | Web 控制台 | jar | spring-boot3-brick-bootkit |
| `sdk` | 插件侧注解 | jar | core |
| `scripts` | 脚本能力 | jar | spring-boot3-brick-bootkit |
| `maven-packager` | Maven 打包插件 | maven-plugin | common |
| `spring-boot-starter` | 统一 Starter | jar | spring-boot3-brick-bootkit + sdk |

## ✅ 增强能力依赖（2026-08 起）

以下能力默认可用，个别需要额外依赖：

| 能力 | 默认状态 | 可选依赖 / 开关 |
| --- | --- | --- |
| 安全中心 | ✅ 默认 | 无（内置代码扫描/策略） |
| 服务注册中心 | ✅ 默认 | 无（`@BrickService` 自动注册） |

| 日志查看 | ✅ 默认 | 需存在可读日志文件（`logging.file.name` 或 `logs/` 目录） |

## 🤖 CI 当前覆盖

- GitHub Actions 当前基线为 `ubuntu-latest + Java 17`
- 稳定测试模块当前覆盖 `loader / core / spring-boot3-brick-bootkit`
- Web 模块单元测试：9 个 Controller + 10 个 Service + 3 个既有 Service 测试
- 前端控制台：Node 20 下 `npm ci` + `npm run build`，并校验构建产物已提交
- docs-website：Node 20 执行校验和构建

## ⚠️ 不在承诺范围

以下组合不在回归矩阵，遇到问题优先按“升级到基线”处理，不视为框架缺陷：

- Java 8 / 11 / 21 及以上：未做构建与字节码验证
- Spring Boot 2.x：brick-bootkit 3.x 仅面向 Spring Boot 3.x
- 非 Linux runner（Windows / macOS）下的 Maven 构建：CI 不覆盖，本地可用但回归不保证
- Gradle 构建：当前仅 Maven 打包器经过验证
- 插件市场远程下载：依赖目标下载源可达性，未纳入 CI 网络回归

## 🔄 版本同步约定

任何基线变更（Java / Spring Boot / Maven / Node）必须同步：

1. 父工程 `pom.xml` 的 `<properties>` 版本号
2. `.github/workflows/ci.yml` 的 setup-java / setup-node 版本
3. 本页“官方基线”表格
4. README 顶部“快速接入”章节的环境要求

## 🧭 迁移兼容

- 3.x → 4.x：`PluginManager` 接口方法签名保持兼容，`install(Path)` 取代旧 `installPlugin(File)`；`PluginService` / `BrickService` 注解可共存
- 4.0.x 内部：starter 已统一走主框架运行时，旧 core 模块弃用版 `PluginManager` 不再被 starter 引用
- 插件包格式：`maven-packager` 产出的 jar/zip 格式向后兼容 3.x 插件包
