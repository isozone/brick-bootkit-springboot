# 统一迁移向导

如果你不想逐个运行 preflight、 slicer、scaffold 三个命令，
迁移向导把这三步串成一条命令，一键完成从体检到骨架生成的全过程。

---

## 用法

```bash
# 交互模式（会提示选择候选包）
./tools/migrate/migrate.sh /path/to/project

# 自动模式（自动选评分最高的候选包）
./tools/migrate/migrate.sh /path/to/project --auto

# 覆盖已存在的输出目录
./tools/migrate/migrate.sh /path/to/project --auto --force
```

参数：

| 参数 | 说明 |
| --- | --- |
| `<项目路径>` | 要迁移的存量项目根目录 |
| `--auto` | 自动选择评分最高的候选包，不交互 |
| `--force` | scaffold 输出目录已存在时覆盖 |

---

## 执行流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  preflight  │ -> │   slicer    │ -> │  scaffold   │
│  体检       │    │  切片分析   │    │  生成骨架   │
└─────────────┘    └─────────────┘    └─────────────┘
      │                  │                  │
   有阻断项           无候选包            完成
   直接退出           给出建议            输出配置
```

### 步骤 1：preflight 体检

向导首先运行 `preflight`，检查项目是否满足接入条件。

- **有阻断项**：直接退出，打印阻断项列表，需先解决后再来
- **无阻断项**：继续下一步

### 步骤 2：slicer 切片分析

自动运行 `slicer`，列出候选切片。

- **交互模式**：提示用户输入序号选择候选包（回车默认选第一个）
- **自动模式**：直接选评分最高的包

### 步骤 3：scaffold 生成骨架

根据选定的包名，自动调用 `scaffold` 生成插件模块骨架。

完成后输出：
- 插件骨架路径
- 建议的 `application.yml` 配置
- L0/L1/L2 验证顺序指引

## 与分步工具的对应关系

| 向导步骤 | 底层调用 | 单独运行对应命令 |
| --- | --- | --- |
| 体检 | `./tools/preflight/preflight.sh` | [8.旧项目渐进式接入指南](./8.旧项目渐进式接入指南.md) |
| 切片 | `./tools/slicer/slice.sh` | [9.业务切片分析指南](./9.业务切片分析指南.md) |
| 骨架 | `./tools/scaffold/scaffold.sh` | [10.插件骨架生成器](./10.插件骨架生成器.md) |

向导只是串联器，底层逻辑与分步工具完全一致。遇到问题可以单独运行对应工具排查。

---

## 限制

- 需要 Python 3 解析 slicer JSON（用于候选包列表提取）
- 交互模式需要终端支持标准输入
- 阻断项不会自动修复，仍需人工处理
