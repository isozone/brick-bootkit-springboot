# 4.0.11 更新日志

## 🔧 工程化与代码质量对齐（2026-08）

本版本聚焦**工程化治理与测试基建补全**，无对外 API 破坏性变更，全部向后兼容。

### 1. 工具类去重（消除重复实现）
- `CompareClassTypeUtils` / `ObjectUtils` / `FilesUtils` / `SpringBeanUtils` 的重复副本从 `loader`、`bootstrap`、主模块收敛到 `common` 模块，删除冗余实现，统一维护入口。
- `loader` 版 `ResourceUtils` 重命名为 `PluginResourceUtils`，消除与 `common.ResourceUtils` 的同名混淆（两者场景不同：前者面向插件类加载 / jar-URL 资源探测，后者为通用资源定位）。

### 2. 版本号与配置对齐
- 文档、模板、示例中的版本号 `4.0.10` → `4.0.11` 统一。
- 清理根 POM 死配置：`powermock.version`、`grpc-starter.version` 两个不再使用的版本属性。

### 3. 日志规范化
- `scripts` 模块主代码中的 `System.out/err` 改为 SLF4J（`AbstractScriptExecutor` 异常路径改为 `log.error`）。

### 4. 测试与质量门禁
- 修复 JaCoCo 配置：移除 `<skip>true</skip>`，恢复覆盖率报告生成。
- 新增 JaCoCo `check` 门禁（指令覆盖率目标 0.80、分支覆盖率目标 0.40），当前 `haltOnFailure=false`，仅告警不阻断，待覆盖率提升后收紧。
- 补全单元测试，消除零测试模块：`common` 20 个、`sdk` 3 个、`spring-boot-starter` 5 个。

### 5. 版权头统一
- 801 个 Java 文件统一为 Apache 2.0 版权头，保留原始 `starBlues` 作者署名（fork 合规）。

## 📚 文档同步
- `readme.md`：新增「功能成熟度」小节，标注核心能力已就绪与高级特性（集群 / 灰度 / 分布式）需生产前验证。
- `doc/updates/4.0.11.md`：本更新日志。

## ✅ 测试
- `common` / `sdk` / `spring-boot-starter` 新增单元测试全部通过。
- 全量 13 模块 `mvn test` BUILD SUCCESS。

## ⬆️ 升级注意
- **零配置升级**：无 API 破坏性变更，无需修改配置即可升级。
- 若需启用覆盖率门禁阻断，可将根 POM 中 JaCoCo `check` 的 `haltOnFailure` 改为 `true`。
