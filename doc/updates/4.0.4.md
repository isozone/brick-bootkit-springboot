# Brick BootKit 4.0.4 更新日志

## 📅 发布日期
2025-01-29

## 🎯 版本概述

Brick BootKit 4.0.4 是一个重大更新版本，在保持对 Spring Boot 2.x 兼容的同时，全面支持 Spring Boot 3.5.x 和 JDK 17+。本版本修复了多个关键问题，并引入了全新的 Web 管理控制台，大幅提升了开发体验和运维效率。

---

## ✨ 新增功能

### 1. 🌐 全新 Web 管理控制台

**模块**: `spring-boot3-brick-bootkit-web`

新增了一个功能强大的可视化 Web 管理控制台，提供以下功能：

#### 插件管理
- ✅ 插件列表展示（状态、版本、描述等）
- 📤 插件上传安装（支持拖拽上传）
- ▶️ 插件启动/停止
- 🔄 插件重启
- 🗑️ 插件卸载
- 📋 插件信息查看
- 📜 插件日志查看

#### 系统监控
- 📊 **内存监控**：堆内存、非堆内存使用情况及趋势图
- 💻 **CPU 监控**：系统负载、进程 CPU 使用率
- 🧵 **线程监控**：当前线程数、守护线程、峰值线程
- 📈 **插件统计**：插件总数、运行中、已停止、异常状态

#### API 文档
- 📚 集成 Knife4j 自动生成 REST API 文档
- 🔍 在线 API 测试功能
- 📖 完整的接口说明

#### 技术栈
- 前端：Thymeleaf + Vue 3 + Bootstrap 5
- 图表：ECharts 实现数据可视化
- API 文档：Knife4j (OpenAPI 3)
- 监控指标：Micrometer 集成

#### 使用方式
```xml
<dependency>
    <groupId>com.zqzqq</groupId>
    <artifactId>spring-boot3-brick-bootkit-web</artifactId>
    <version>4.0.4</version>
</dependency>
```

```java
@SpringBootApplication
@EnableBrickWeb
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

访问地址：`http://localhost:8080/plugins-web/index`

## 🐛 Bug 修复

### 核心问题修复

1. **修复开发环境无法识别插件问题**
   - 问题：dev 模式下插件无法被正确识别和加载
   - 影响：开发环境无法正常使用插件功能
   - 解决：优化插件扫描和加载逻辑

2. **修复启动一段时间后自动终止问题**
   - 问题：主应用运行一段时间后会自动停止
   - 影响：系统稳定性严重受损
   - 解决：修复生命周期管理和线程池配置问题

3. **修复启动之后日志打印乱码问题**
   - 问题：日志输出出现中文乱码
   - 影响：日志无法正常阅读
   - 解决：统一日志编码配置为 UTF-8

4. **修复内存泄漏问题**
   - 问题：长时间运行后内存占用持续增长
   - 影响：可能导致系统崩溃
   - 解决：优化类加载器和资源释放机制

5. **修复插件初始化问题**
   - 问题：插件初始化过程中出现异常
   - 影响：插件无法正常启动
   - 解决：改进初始化流程和异常处理

6. **修复隔离模式 dev 无法加载插件问题**
   - 问题：隔离模式下 dev 环境插件加载失败
   - 影响：开发调试困难
   - 解决：修复类加载器隔离配置

### Web 管理控制台问题修复

7. **修复 Knife4j 问题**
   - 问题：API 文档无法正常显示
   - 影响：开发者无法查看 API 文档
   - 解决：修复 Knife4j 配置和依赖冲突

8. **修复上传插件历史记录问题**
   - 问题：插件上传历史记录无法正确保存
   - 影响：无法追踪插件上传历史
   - 解决：修复历史记录存储逻辑

9. **修复上传插件问题**
   - 问题：插件上传失败或上传后无法安装
   - 影响：无法通过 Web 界面安装插件
   - 解决：优化文件上传和处理流程

## 🚀 快速开始

### 1. 主应用配置

```yaml
plugin:
  enable: true
  runMode: dev
  plugin-follow-log: true
  mainPackage: com.your.package.YourApplication
  pluginPath:
    - ./plugins
```

### 2. 启动类配置

```java
@SpringBootApplication
@ComponentScan(basePackages = {"com.zqzqq.bootkits.*", "your.package"})
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

### 3. 启用 Web 管理控制台

```java
@SpringBootApplication
@EnableBrickWeb
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

访问：`http://localhost:8080/plugins-web/index`

## 📖 配置说明

### 主应用配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `plugin.enable` | Boolean | true | 是否启用插件功能 |
| `plugin.runMode` | String | dev | 运行模式：dev（开发）/ prod（生产） |
| `plugin.plugin-follow-log` | Boolean | true | 是否跟随主应用日志输出 |
| `plugin.mainPackage` | String | - | 主应用启动类全限定名 |
| `plugin.pluginPath` | List | [] | 插件存储路径列表 |

### Web 控制台配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `plugin.web.enabled` | Boolean | true | 是否启用 Web 管理控制台 |
| `plugin.web.enable-ui` | Boolean | true | 是否启用 UI 界面 |
| `plugin.web.api-prefix` | String | /plugins-web/api | API 路径前缀 |
| `plugin.web.page-prefix` | String | /plugins-web | 页面路径前缀 |
| `plugin.web.static-path-prefix` | String | plugins | 插件静态资源访问前缀 |
| `plugin.web.monitor-refresh-interval` | Integer | 5 | 监控数据刷新间隔（秒） |

### 插件静态资源配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `plugin.resources.static-locations` | List | [] | 插件静态资源路径，支持 `classpath:` 和 `file:` 前缀 |

**示例**：
```yaml
plugin:
  resources:
    static-locations:
      - classpath:/static/
      - file:/opt/plugins/assets/
```

访问插件静态页面：`http://host:port/{static-path-prefix}/{pluginId}/index.html`

## 🔄 迁移指南

### 从 4.0.3 升级到 4.0.4

#### 1. 更新依赖版本

```xml
<dependency>
    <groupId>com.zqzqq</groupId>
    <artifactId>spring-boot3-brick-bootkit</artifactId>
    <version>4.0.4</version>
</dependency>
```

#### 2. 更新配置文件

将旧配置格式迁移到新格式：

**旧配置（4.0.3）**：
```yaml
plugin:
  plugin-path: ./plugins
  plugin-config-file-name: plugin.yaml
  enable: true
  load-mode: isolation
```

**新配置（4.0.4）**：
```yaml
plugin:
  enable: true
  runMode: dev
  plugin-follow-log: true
  mainPackage: com.your.package.YourApplication
  pluginPath:
    - ./plugins
```

#### 3. 更新插件静态资源配置（可选）

如果插件中配置了静态资源路径，需要更新配置前缀：

**旧配置（4.0.3）**：
```yaml
spring:
  resources:
    static-locations:
      - classpath:/static/
```

**新配置（4.0.4）**：
```yaml
plugin:
  resources:
    static-locations:
      - classpath:/static/
```

#### 4. 添加 Web 管理控制台（可选）

```xml
<dependency>
    <groupId>com.zqzqq</groupId>
    <artifactId>spring-boot3-brick-bootkit-web</artifactId>
    <version>4.0.4</version>
</dependency>
```

```java
@EnableBrickWeb
```
