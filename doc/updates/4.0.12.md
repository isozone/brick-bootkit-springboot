# 4.0.12 更新日志

## 🔌 Brick Protocol 闭环：热插拔 + EventBus 桥接 + 跨进程传输（2026-09）

本版本将 Brick Protocol（语义协议）从"协议定义"推进到"运行闭环"，全部向后兼容，无 API 破坏性变更。

### 1. 设备注册表增强（热插拔 / 并发 / 运维）

- `DeviceRegistry` 重入锁化：register / unregister 原子化，杜绝并发竞态。
- 监听器改为 `CopyOnWriteArrayList`，注册/注销通知线程安全。
- 新增 `reconnect(deviceId)`：断线重连（断开旧连接 + 复用 TransportContext 重建）。
- 新增 `startHealthCheck(intervalMs)` / `stopHealthCheck()`：周期性检查 adapter 连接状态并自动重连。
- `shutdown()` 采用迭代器安全删除，保证停机无残留。
- 新增 `DeviceRegistryHotPlugTest`（8 个）：并发注册注销、热插拔中持续发布、重连失败降级等。

### 2. EnvelopeBus ↔ PluginEventBus 双向桥接

- 新增 `EnvelopeBusBridge`（core/eventbus）：
  - **上行**：adapter 发布信封 → EnvelopeBus → `PluginEvent(DEVICE_EVENT)` → 业务插件。
  - **下行**：业务插件发 DEVICE_EVENT → 还原为信封 → EnvelopeBus → adapter。
- 防环机制：`ThreadLocal` 传播标记阻止双向循环。
- `PluginEvent.EventType` 新增 `DEVICE_EVENT`。
- 生命周期消息不参与桥接。
- 自动配置中 `EnvelopeBusBridge` bean 仅在 `PluginEventBus` 存在时激活（`@ConditionalOnBean`）。

### 3. 跨进程传输（EnvelopeTransport SPI + MQTT 参考实现）

**协议模块（保持零运行时依赖）**
- `EnvelopeTransport` SPI：跨进程传输的唯一抽象（start/stop/publish + TransportListener），传输层只搬字节、不感知语义。
- `RemoteEnvelopeBus`：本地 `EnvelopeBus` + 远程 transport 双管道编排器。
  - 上行：transport 收到远端消息 → 本地 bus 发布。
  - 下行：本地 bus 的 REQUEST/COMMAND → transport 发往远端；EVENT/REPLY 不转发。
  - `AtomicBoolean` 防环。
- 新增 `RemoteEnvelopeBusTest`（12 个）：上下行桥接、防环、异常容错、多消息。

**新增模块 `spring-boot3-brick-bootkit-transport-mqtt`（Eclipse Paho MQTT 3.1.1）**
- `MqttTransportConfig`：broker / clientId / topic 前缀 / QoS 配置 + topic 构建与解析。
- `MqttEnvelopeTransport`：信封 JSON 序列化上云，topic 规则 `brick/{deviceId}/{capabilityId}`，QoS 映射（FIRE_FORGET→0 / AT_LEAST_ONCE→1），自动重连。
- `RemoteEnvelopeBusAutoConfiguration`：`brick.transport.mqtt.*` 属性绑定，`@ConditionalOnClass` 按需激活。
- 集成模块对 transport-mqtt 为 **provided + optional** 依赖，不强制用户引入。

**跨进程闭环示意**
```
进程 A（边缘 adapter）：ModbusRtuDeviceAdapter → EnvelopeBus ⇄ MQTT broker
进程 B（业务应用）：   RemoteEnvelopeBus ⇄ EnvelopeBus → 业务插件
```
