# Brick BootKit 4.0.6 更新日志

## 发布日期
2026-03-26

## 本次重点

### 1. 宿主接入门槛继续降低
- 标准 Spring Boot 宿主会优先自动推断 `plugin.mainPackage`
- 新增最小模板：
  - `templates/host-minimal`
  - `templates/plugin-minimal`
- 新增故障示例模板：
  - `templates/host-broken-main-package`
  - `templates/host-broken-plugin-path`
  - `templates/plugin-broken-packaging`

### 2. 新增 doctor 自检与导出能力
- 新增接口：
  - `GET /plugins-web/api/doctor`
  - `GET /plugins-web/api/doctor/export/text`
  - `GET /plugins-web/api/doctor/export/json`
- 启动完成后会输出 doctor 摘要日志

### 3. Web 管理台更适合新手
- 首页新增 doctor 摘要与首次接入 checklist
- 系统概览页新增环境自检卡片
- 上传插件页升级为分步向导，并能给出下一步建议
- 统一错误面板支持显示错误码和排障文档入口

### 4. 错误码与排障链路打通
- doctor 结果、Web 异常、排障文档页和前端提示统一到同一套问题目录
- Web 返回支持 `errorKey / hintPath / hintAnchor`
