# Brick BootKit 4.0.5 更新日志

## 发布日期
2026-02-20

## 本次重点

### 1. 单插件启动测试能力增强（独立/共享）
- 支持在 `@OneselfConfig` 中直接声明 `developmentMode`，单插件本地启动可在 `isolation` / `coexist` 间切换。
- 支持通过 JVM 参数或环境变量覆盖开发模式：
  - `plugin.developmentMode`
  - `spring-boot3-brick-bootkit.developmentMode`
  - `developmentMode`
  - `PLUGIN_DEVELOPMENT_MODE`
- `ProdLauncher` 启动主程序包时优先读取 `Main-Development-Mode`（Manifest）；若未配置则回退到上述参数链路。
- 单插件 `coexist` 模式下，`@AutowiredType.MAIN` 在无主应用上下文时可回退到插件容器，避免本地调试直接失败。

### 2. 无 `PLUGIN.META` 的本地直跑支持
- IDE 直接运行插件入口、尚未产出 `META-INF/PLUGIN.META` 时，框架会自动构建临时插件描述信息并继续启动。
- 支持通过以下参数覆盖临时描述信息：
  - `plugin.standalone.id`
  - `plugin.standalone.version`
  - `plugin.standalone.bootstrapClass`
  - `plugin.standalone.description`
  - `plugin.standalone.provider`
  - `plugin.standalone.requires`
  - `plugin.standalone.license`
  - `plugin.standalone.args`
  - `plugin.standalone.configFileName`
  - `plugin.standalone.configFileLocation`

### 3. Maven 打包插件新增 `prepare-meta` 目标
- 新增目标：`spring-boot3-brick-bootkit-packager:prepare-meta`
- 默认阶段：`process-classes`
- 作用：在编译阶段预生成开发态元文件（`PLUGIN.META` / `RESOURCES.CONF` / `MANIFEST.MF`），便于单插件本地启动测试。
- 与 `repackage` 互补：
  - `prepare-meta`：本地调试链路
  - `repackage`：发布与交付链路

### 4. 打包器健壮性修复
- 修复 `BasicRepackager` 在 source jar 没有 `MANIFEST.MF` 时可能出现的空指针问题。

### 5. 测试与示例
- 新增 `PrepareMetaMojoTest`，覆盖：
  - 元文件生成校验
  - `loadToMain` 依赖标记保留校验
- 示例工程 `demo-test-upload-plus` 已接入 `prepare-meta`。

## 升级建议
- 需要单插件本地调试的插件工程，建议在 packager 执行列表中同时保留：
  - `prepare-meta`
  - `repackage`
