# 4.0.9 更新日志

## 🚀 新能力（2026-08）

本版本在既有插件框架基础上新增 9 项增强能力，均接入主链路与 Web 控制台，默认向后兼容。

### 1. 插件安全中心
- 安装阶段自动执行安全准入检查（`PluginSecurityAdmissionCheck`，接入 Admission Pipeline）
- 代码扫描（危险/可疑模式）、权限与安全策略校验、文件系统/网络访问检查
- 1-2 个违规 -> WARN；3 个及以上违规 -> REJECT（enforce 模式阻断安装）
- Web 页面「安全中心」+ `/plugins-web/api/security/*` 接口

### 2. 插件服务注册中心
- 新增 `PluginServiceRegistry` Bean（`DefaultPluginServiceRegistry`）
- 插件启动时自动扫描 `@PluginService`/`@BrickService` 注册服务（`ServiceRegistryLifecycleExtension`）
- `@BrickServiceReference` 跨插件服务字段自动注入（JDK 动态代理，兼容 ClassLoader 隔离）
- Web 页面「服务注册中心」+ `/plugins-web/api/registry/*` 接口

### 3. 插件配置热更新
- 新增 `PluginConfigurationManager` Bean（core `PluginConfigurationAutoConfiguration` 注册）
- 配置热更新、版本历史、回滚能力
- Web 页面「插件配置」+ `/plugins-web/api/configurations/*` 接口

### 4. 性能分析与资源隔离
- 新增 `QuotaManager`/`PluginResourceMonitor`/`PluginResourceIsolation`/`PluginPerformanceAnalyzer` Bean
- 性能评分、资源占用监控、配额管理
- Web 页面「性能分析」+ `/plugins-web/api/performance/*` 接口

### 5. 集群管理
- Redis 分布式锁 `RedisClusterLockProvider`（可选依赖，无 Redis 时回退文件锁）
- 集群节点注册/心跳（`ClusterNodeRegistry`）、插件状态同步（`PluginClusterStateSync`）
- Web 页面「集群管理」+ `/plugins-web/api/cluster/*` 接口

### 6. 插件依赖分析
- 新增 `PluginDependencyManager` Bean，基于真实插件描述符构建依赖图
- 依赖图、兼容性检查、升级影响面分析、版本矩阵
- Web 页面「依赖分析」+ `/plugins-web/api/dependency/*` 接口

### 7. 灰度发布 UI
- 灰度机制（`plugin.rolloutMode=gray` + `PluginRolloutProbe`）接入 Web 控制台
- 灰度配置查看、探针列表、决策模拟
- Web 页面「灰度发布」+ `/plugins-web/api/rollout/*` 接口

### 8. 事件总线可视化
- 新增 `PluginEventBus` Bean，支持插件间异步通信
- Web 页面「事件总线」+ `/plugins-web/api/eventbus/*` 接口（事件统计/类型/最近事件流）

### 9. 插件日志查看
- 尾部读取应用日志 + 插件 ID/关键字过滤（多级探测日志文件位置）
- Web 页面「插件日志」+ `/plugins-web/api/logs/*` 接口

### 10. 插件市场
- 远程/classpath 插件索引（`plugin.web.marketplace-index-url`），下载 + 复用安装流程
- Web 页面「插件市场」+ `/plugins-web/api/marketplace/*` 接口

## 🔧 架构与工程改进

- **统一 Starter**：`spring-boot3-brick-bootkit-spring-boot-starter` 统一依赖主框架真实运行时，弃用 core 简化版 PluginManager；新增 `PluginEventBus` Bean 与 `brick-bootkit.*` 兜底配置
- **doctor 扩展**：环境自检新增 8 项能力维度（安全/注册/配置/事件/依赖/性能/集群/灰度）
- **Maven Wrapper 修复**：重建 `.mvn/wrapper/`（maven-wrapper-3.3.2），`mvnw` 可直接使用
- **前端构建**：Vue3 控制台 `npm run build` 产物接入 web 模块 static 目录
- **CI 完善**：新增 `web-console-frontend` job（`npm ci` + `npm test` + `npm run build` + 产物校验）
- **测试体系**：9 个 Controller + 10 个 Service 单元测试、注入器/组件/集成测试、前端 vitest
- **文档**：`doc/5.API清单.md` 新增，兼容矩阵细化，readme 同步新能力
- **模板**：新增 `host-cluster`/`host-grayscale`/`plugin-with-dependency`/`plugin-capability-demo`

## ⚠️ 升级注意

- 配置热更新：`PluginConfigurationManager` 由 core `PluginConfigurationAutoConfiguration` 注册，主框架不再重复注册（清理 `@EnableConfigurationProperties` 重复绑定）
- 集群锁：引入 `spring-boot-starter-data-redis` 后自动启用 Redis 锁，否则回退文件锁；`RedisClusterLockConfiguration` 独立装配（无 Redis 依赖时不影响类加载）
- 前端国际化：控制台已引入 vue-i18n（默认中文，`localStorage.brick-locale=en-US` 可切换）
